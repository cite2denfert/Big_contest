## 0. 한눈에 보기

| 구분 | 데이터 | 분석에서 쓴 방식 |
|---|---|---|
| 제공 | 신한카드 데이터1 (일 × 6시간대 × 업종 × 성별 × 연령) | **주 분석 데이터.** 법인 결제와 비상권 업종 13개를 빼고 업종군 12개로 묶음 |
| 제공 | 신한카드 데이터2 (일 × 업종 × 고객 거주지) | 고객 거주지로 **외지 고객과 강원 고객 구분** |
| 제공 | SK 유동인구 (월 단위) | 지역 특성 비교용. 일 단위가 아니어서 날씨 분석에는 쓰지 않음 |
| **외부** | **기상청 관측자료** (춘천 ASOS 101, 강남 AWS 400) | 일·시간 강수량과 기온. 2025.7~12 + 평년 비교용 2015~2024 일자료 |

공모전 규칙상 외부 데이터는 무료 공개 자료만 쓸 수 있고, **출처와 수집 방법을 적고 원본 파일을 함께 제출**해야 합니다. 지금까지 쓴 외부 데이터는 기상청 자료 하나입니다.

## 1. 제공 데이터: 신한카드

### 1-1. 파일 구조

| 항목 | 데이터1 | 데이터2 |
|---|---|---|
| 파일 | `신한카드_빅콘테스트2026_데이터1.txt` | `신한카드_빅콘테스트2026_데이터2.txt` |
| 읽는 법 | 탭 구분, **cp949 인코딩** | 탭 구분, cp949 인코딩 |
| 행 수 | 1,044,710 | 1,806,800 |
| 기간 | 2025-07-01 ~ 2025-12-31 (184일) | 같음 |
| 컬럼 | TA_YMD, TIME_GB, MCT_SGG_CD, MCT_RY_CD, SEX_CCD, AGE_CCD, TS_AT, USE_CNT | TA_YMD, MCT_SGG_CD, MCT_RY_CD, **CLN_SGG_CD**, SEX_CCD, AGE_CCD, TS_AT, USE_CNT |
| 시간대 | TIME_GB: 00_05, 06_11, 12_17, 18_23 | 없음 |
| 성별 | 남성, 여성, **법인** | 남성, 여성 (법인 없음) |

**확인한 사실**
- 결측값과 키 중복 행은 없습니다.
- 결제건수(USE_CNT) 최솟값이 5입니다. 5건 미만 칸은 비식별 처리로 빠진 것으로 보입니다.
- **데이터2 = 데이터1에서 법인을 뺀 것**입니다. 지역별 총액이 정확히 같습니다(춘천 20,611억, 강남 280,899억).

### 1-4. 날짜와 고객 거주지

- **공휴일**: 8/15, 10/3, 10/5~10/9, 12/25.
  - **추석 연휴는 10/3~10/9 전체**를 하나로 봅니다. 주말인 10/4도 포함합니다.
  - 12/24와 12/31은 "연말 전야"로 따로 표시합니다.
- **고객 거주지 (데이터2 CLN_SGG_CD)**: 값이 시도 단위입니다(강원, 경기, 서울 등).
  - 거주 시도가 "강원"이 아니면 **외지 고객**으로 분류했습니다.
  - "강원"에는 춘천 밖 강원 거주자도 들어갑니다.

### 1-5. 분석용 표 만들기

1. 정제한 카드 데이터를 **지역 × 업종군(또는 업종) × 날짜**로 결제금액(TS_AT)을 더합니다.
2. 같은 날짜의 기상 자료와 **날짜(TA_YMD) + 지역(MCT_SGG_CD)**으로 붙입니다. 카드 파일과 기상 파일의 지역명이 같아서 그대로 결합됩니다.

## 3. 외부 데이터: 기상청 관측자료

### 3-1. 출처와 수집 방법

| 항목 | 내용 |
|---|---|
| 제공기관 | 기상청 국가기후데이터센터, **기상자료개방포털** (data.kma.go.kr). 무료 공개 |
| 관측소 | 춘천 ASOS 101 (종관기상관측), 강남 AWS 400 (방재기상관측) |
| 기간 | 2025-07-01 ~ 2025-12-31 시간·일 자료 + **2015-01-01 ~ 2024-12-31 일자료(평년 비교용)** |
| 항목 | 강수량, 기온(최고·최저), 습도, 풍속 등 |
| 수집 방법 | 공개 조회 화면에 관측소·기간·자료형태·기상요소 조건을 넣고, 응답에 담긴 관측값을 추출함 |
| 수집 조건 | API 인증키나 로그인 전용 다운로드는 쓰지 않음. 조회 화면이 최대 10행만 보여 줘서 시간자료는 10시간, 일자료는 10일 단위로 나눠 요청함 |
| 수집 코드 | `scripts/download_weather.py`<br>2025년 자료: `--download`<br>10년 일자료: `--climatology` |
| 원본 보관 | `raw/**/*.html.gz`: 기상청 응답 원본을 그대로 압축<br>`*.request.json`: 각 요청의 주소·조건·수집 시각·SHA-256 해시 |

- 조회 화면 주소
  - 춘천 ASOS: <https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36>
  - 강남 AWS: <https://data.kma.go.kr/data/grnd/selectAwsRltmList.do?pgmNo=56>

### 3-3. 정제 규칙

| 문제 | 처리 |
|---|---|
| 강수량 빈칸 (ASOS) | 원본 파일에는 빈칸 그대로 두고, **분석할 때 0(무강수)으로 처리**. 기상청은 비가 안 온 날 강수량을 비워 둠 |
| 강남 관측 공백 | 2025-09-10 09시 ~ 09-11 17시 시간자료와 9/11 일자료가 없음 → 해당 날짜를 강남 분석에서 제외. 송파 값으로 대체하거나 보간하지 않음 |
| 춘천 | 요청한 모든 시각·날짜의 행이 있음 |
| 2026-01-01 00시 행 | 12/31 마지막 강수 구간 처리용 보조 행 → 분석에서 제외 |
| 일 최고·최저기온 | 시간자료에서 계산하지 않고 기상청 공식 일 값을 씀 |
